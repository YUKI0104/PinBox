# PinBox — 把任意窗口「置顶」成浮窗

菜单栏小工具：选一个窗口，它就被镜像成一个**永远在最上层的浮窗**，可以拖动、缩放、看剧、挂机、盯进度。
不限于某个模拟器，**任何 App 的窗口都行**。

> 当前版本 **v0.1.0**（早期版本，功能已可用）

<img src="Resources/AppIcon.png" width="96" alt="PinBox">

## 功能

- 菜单栏常驻，**没有 Dock 图标**
- 两种选窗口方式：**点击窗口选择**（全屏遮罩 + 高亮，点哪选哪）或**从列表选择**（带 App 图标）
- 浮窗可拖动、可缩放，**比例锁定**：画面永远完整，不会被裁切或拉变形
- 位置和大小自动记住
- **自动跟随源窗口**：源窗口变大变小、横屏竖屏切换都能跟上
- **自动重连**：源窗口消失 / 被重建 / 采集中断时不会退出，会自己接回来
- **画面裁切**：带实时预览，可精确去掉源窗口自带的标题栏 / 工具栏；每个 App 记住自己的裁切值
- 点浮窗**没有任何副作用**：不穿透到下面的窗口，也不会激活源窗口 —— 它只负责显示

## 安装

从 [Releases](../../releases) 下载 `PinBox-<版本>.dmg`，双击打开，把 **PinBox** 拖进「应用程序」。

应用**未做 Apple 公证**（本机自签名），首次打开如果被拦住，右键点图标选「打开」，或：

```bash
xattr -dr com.apple.quarantine /Applications/PinBox.app
```

### 权限

| 权限 | 必需？ | 用途 |
|---|---|---|
| **屏幕录制** | **必需** | 抓取目标窗口画面。首次启动会弹窗，或去 系统设置 → 隐私与安全性 → 录屏与系统录音 里把 PinBox 打开 |
| 辅助功能 | 可选 | 只用来自动识别标题栏高度（「自动识别标题栏」按钮）。不授权就手动填裁切数值 |

> 授权之后如果浮窗还没出现，**退出再重新打开一次 PinBox** —— macOS 需要重启 App 才会认到新的屏幕录制授权。

## 使用

菜单栏图钉图标：

| 菜单项 | 说明 |
|---|---|
| **点击窗口选择…** | 屏幕变暗，鼠标移到哪个窗口就高亮哪个，点一下即选中（Esc 取消）|
| **最近 / 可选窗口** | 直接从列表里挑 |
| **显示浮窗** | 临时隐藏 / 显示 |
| **重置浮窗位置** | 回到右上角 |
| **设置…** | 打开设置面板 |

设置面板：

- **目标窗口** —— 当前映射的窗口、源窗口尺寸、两种选择方式、自动跟随 / 自动重连开关
- **画面裁切** —— 上/右/下/左 四个数值 + **自动识别标题栏** + **实时预览**（预览就是浮窗里正在显示的画面，改完立刻能看到效果）
- **浮窗** —— 不透明度、圆角、层级、显示边框、重置位置
- **性能** —— 帧率 15 / 24 / 30 / 60
- **系统** —— 屏幕录制 / 辅助功能权限状态、开机自启

### 浮窗操作

- **拖动画面** = 移动浮窗（单击原地不动）
- **拖动四边 / 四角** = 缩放；比例锁定为画面比例
- 鼠标悬停时边框变亮，方便看清边界

### 典型用法：只显示除操作栏外的画面

以模拟器为例：它的窗口顶部有一排自己的操作栏。用「自动识别标题栏」按钮，或手动把**上**填成实测值
（MuMu 38、Finder 52、Otty 32 —— 都是点），浮窗里就只剩纯画面了。这个值会被记住，下次选同一个 App 自动套用。

## 它是怎么工作的（以及为什么不能用"真置顶"）

macOS **不允许一个程序修改另一个程序窗口的层级**，能试的路都试过：

| 方法 | 结果 |
|---|---|
| SkyLight 私有 API `SLSSetWindowLevel` | 返回成功，但 `CGWindowList` 里层级仍是 0，画面照样被前台窗口盖住（静默失败）|
| `DYLD_INSERT_LIBRARIES` 注入 | 目标 App 带 hardened runtime（MuMu、绝大多数商业软件）时被拒 |
| Accessibility `AXRaise` | 只能抬到**前台 App 主窗口之下**，压不过全屏的前台窗口 |

所以只剩一条路：**ScreenCaptureKit 抓窗口画面 → 自己开一个高层级窗口渲染**。
自己的窗口才能改层级，而且源窗口被完全遮住时也能正常显示（抓的是窗口自身的表面）。
`fuwa`、`pin-top` 等开源置顶工具走的也是这条路。

## 系统要求

- macOS 14 或更高（用到 `SCStreamConfiguration.sourceRect`）；在 macOS 27 / Apple Silicon 上开发验证
- 无需关闭 SIP，不注入任何进程

## 从源码构建

```bash
./create-identity.sh   # 建议先跑一次：创建固定签名身份，屏幕录制授权在重新构建后依然有效
./build.sh             # 编译 + 打包成 dist/PinBox.app（版本号取自 Resources/Info.plist）
./install.sh           # 安装到 /Applications 并启动
./make-dmg.sh          # 生成 dist/PinBox-<版本>.dmg
```

只需要 Xcode Command Line Tools（不需要完整 Xcode），无第三方依赖。

## 已知限制

- 只"看"不"点"：浮窗不转发鼠标 / 键盘。要在源窗口里操作就切到它本身，浮窗会继续显示同样内容
- 画面与源窗口之间有几十毫秒延迟（采集 + CGImage 转换）
- 源窗口最小化后采集会暂停（恢复后自动重连）
- 同一时刻只能置顶一个窗口
